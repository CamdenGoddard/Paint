# Camden's Pain(t)

CS 250 term project - a paint program built in JavaFX, one sprint at a time.

Sprint 1: open an image, menu bar, Save, Save As, Close Image, Exit.
Sprint 2: draw on the canvas, color picker, line width, PNG/JPG/BMP, Help menu, unsaved-changes warning.

See `RELEASE_NOTES.txt` for details.
