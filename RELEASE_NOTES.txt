Camden's Pain(t)  Version 0.4.0  -  10/04/2026
=============================================

Sprint 4 submission for CS 250.

Source code:
  GitHub repo:  https://github.com/CamdenGoddard/Paint
  Tag / release:  v0.4.0  (https://github.com/CamdenGoddard/Paint/releases/tag/v0.4.0)
  This tag matches the code uploaded in the sprint 4 zip.

New features:
  * Undo and Redo (Edit menu, Ctrl+Z / Ctrl+Y). Each tab has its own
    history, built from two stacks (UndoHistory.java): every edit pushes a
    "before" snapshot onto the undo stack; undoing pops it and pushes the
    current picture onto the redo stack; a brand-new edit empties the redo
    stack. History is capped at 40 steps per tab so memory stays bounded.
  * Blank starting image: the program opens with a blank white canvas, and
    File > New Tab (Ctrl+N) gives another one.
  * Clear Canvas (button in the toolbar, or Edit > Clear Canvas,
    Ctrl+Shift+C). It asks "are you sure" first, and can be undone.
  * One more shape of my choice: a five-pointed Star.
  * Regular Polygon with any number of sides (3 to 100, set in the
    "Polygon sides" box). Press at the center and drag outward; the first
    corner follows the mouse, so it rotates as you drag. With 3 sides it is
    an equilateral triangle.
  * Triangles: "Right Triangle" puts the right angle exactly where you
    press the mouse, with legs running horizontally and vertically.
    "Triangle (isosceles)" is the Sprint 3 triangle, and the 3-sided
    polygon is an equilateral triangle - neither of those has a right
    angle.
  * Select tool: drag out a rectangle (shown with a dashed outline), then
    drag inside it to move that piece of the image. The piece moves live
    while you drag and leaves white behind.
  * Edit > Copy, Cut and Paste (Ctrl+C / Ctrl+X / Ctrl+V) work on the
    selection, including between tabs. A pasted
    piece appears just down and right of the original, already selected, and can be dragged into
    place right away.
  * Text tool: type text into the "Text" box (size in "Text size"), pick
    the Text tool, then press and drag on the image. The text follows the
    mouse as a live preview and is placed where you let go.
  * "Live draw": every shape, the text, and moving or pasting a selection
    previews while the mouse is down, and only becomes part of the image
    (and one undo step) when it is finished.
  * Tabs and git are used as in earlier sprints.
  * Small fixes: letting go of the right mouse button mid-drag no longer
    ends a left-button drag early, and shape previews no longer leave
    trails over transparent parts of an opened PNG.

Design notes / assumptions:
  * Undo works by keeping a full snapshot of the canvas before each edit.
    That is simple and easy to get right, at the cost of memory (hence the
    40-step cap).
  * Moving a selection cuts it out, leaving white. Anything dragged
    partly off the edge of the canvas is cropped when it is put down.
  * Selecting, moving and pasting are one undo step each (the whole move
    undoes at once, not pixel by pixel).
  * The selection outline is drawn on a separate transparent layer, so it
    never ends up in a saved file or in an undo snapshot.

Known issues:
  * The selection can only be a rectangle, and text can't be edited or
    moved once it has been placed (use Undo and place it again).
  * Text uses the default font only.
  * Undo history is lost when a tab is closed or reset, and a very large
    opened image uses a lot of memory per undo step.
  * If you type a file name with an extension Save As doesn't offer
    (something other than .png/.jpg/.bmp), it silently saves as PNG - same
    as Sprint 2.
  * The color-name label only recognizes a curated list of common colors;
    anything else reads as "Custom" rather than the closest match.

Critique (current state and code quality):
  The program does everything the Sprint 4 list asks for and the features
  work. ShapeDrawer, UndoHistory and ToolSettings are small and each do one
  job. The weak spot is ImageCanvasTab.java (about 800 lines), which mixes
  file saving, mouse handling and selection logic and should be split up. I
  need to add more files to the program.
